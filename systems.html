Systems of linear equations

A system is a group of equations that must all be true at once.

Solve a small system

x+y=7
x−y=1
  1. Add equations: 2x=8, so x=4.
  2. Substitute into x+y=7: y=3.

Solution: (4,3). Check it in both equations.

Gaussian elimination

Record coefficients and answers in an augmented matrix, then simplify using row operations:

[[1,1 | 7],[1,−1 | 1]]

A system can have one solution, no solution, or infinitely many.

Try it: x+y=9 and x−y=3

Answer: x=6, y=3
