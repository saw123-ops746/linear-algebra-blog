Determinants and inverse matrices

A determinant is a number for a square matrix that tells whether its transformation can be reversed.

Find a 2×2 determinant

For A=[[a,b],[c,d]], det(A)=ad−bc.

det([[2,1],[3,4]])=2·4−1·3=5

What does it mean?

The absolute value gives area scale. If the determinant is zero, the matrix collapses space and has no inverse.

Inverse

An inverse undoes a transformation. For a 2×2 matrix it exists when ad−bc is nonzero:

A⁻¹=(1/(ad−bc))[[d,−b],[−c,a]]
Try it: det([[1,2],[3,5]])

Answer: −1; the matrix is invertible.
