# Linear Algebra Notebook

A beginner-friendly learning site with explanations, worked examples, visual intuition, common mistakes, and self-check questions.

## Learning path
Vectors; matrices; systems of equations; dot products; transformations; vector spaces; determinants and inverses; eigenvalues; applications; practice.

## Reference
The gradual visual approach was inspired by the public [Book-LinearAlgebraLanguage](https://github.com/wanghemath/Book-LinearAlgebraLanguage). Explanations, examples, and code here were written for this site.

## GitHub Pages
This site is served from the repository root. Open `index.html` for the home page; every lesson is a separate HTML page.
