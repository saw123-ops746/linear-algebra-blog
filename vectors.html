What Is a Vector?

A vector is an ordered list of numbers. It can describe a movement by showing how far to go in each direction.

Example

The vector (3, 2) means moving 3 steps east and 2 steps north.

Adding vectors

Add the matching numbers: (3, 2) + (1, 4) = (4, 6).

Try it

What is (2, 1) + (3, 4)?

Answer: (5, 5).
